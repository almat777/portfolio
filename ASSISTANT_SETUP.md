# Подключение ИИ-помощника Алмата

Интерфейс и серверный код готовы. Адрес собственного развёртывания задаётся в `assistant-config.js`; развёртывание Алмата уже подключено в этом файле. При пустом `endpoint` сайт использует подписанные справочные ответы по материалам портфолио. Для генеративных ответов нужен доступный сервер с настроенным ключом и моделью; их работу подтверждает реальный POST-запрос, а не только проверка наличия конфигурации.

## 1. Создай скрипт

1. Открой [Google Apps Script](https://script.google.com/home) под своим Google-аккаунтом.
2. Нажми **Новый проект / New project**.
3. Назови проект **Almat Portfolio Assistant**.
4. Открой локальный файл `apps-script/Code.gs`, скопируй всё его содержимое и вставь вместо начального кода в редактор Apps Script. Сохрани.

В этом одном файле уже собраны проекты, факты об Алмате и серверная логика. Не нужно копировать старые `.gs` файлы аналитики или устанавливать библиотеки.

## 2. Сохрани API-ключ на сервере

1. Получи ключ Gemini API в [Google AI Studio](https://aistudio.google.com/apikey).
2. В Apps Script открой **Настройки проекта / Project Settings** → **Свойства скрипта / Script Properties**.
3. Добавь свойство с именем `GEMINI_API_KEY`, а в значение вставь ключ. Сохрани.

Ключ не нужно отправлять в чат, вставлять в `Code.gs`, `assistant-config.js` или коммитить в GitHub. Использование API зависит от доступности модели, квот и настроек оплаты твоего проекта Google.

Необязательные свойства:

| Имя | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `GEMINI_MODEL` | `gemini-3.5-flash-lite` | Модель Gemini; наличие имени в настройках ещё не подтверждает доступность для аккаунта. |
| `CHATBOT_HOURLY_LIMIT` | `15` | Запросов на браузерный ID за календарный час UTC. |
| `CHATBOT_DAILY_LIMIT` | `60` | Запросов на браузерный ID за календарный день UTC. |
| `CHATBOT_GLOBAL_DAILY_LIMIT` | `150` | Общий суточный предел обращений к модели. |

Актуальность модели проверена 20 октября 2026 года по [документации Gemini](https://ai.google.dev/gemini-api/docs/models). При её последующей замене меняется свойство `GEMINI_MODEL`.

## 3. Разверни веб-приложение

1. **Развернуть / Deploy** → **Новое развертывание / New deployment**.
2. Выбери тип **Веб-приложение / Web app**.
3. **Выполнять от имени / Execute as:** **Меня / Me**.
4. **Кто имеет доступ / Who has access:** **Все / Anyone**, включая посетителей без Google-аккаунта. Вариант «Все с аккаунтом Google» требует входа и не подходит для публичного портфолио.
5. Разверни приложение, проверь и заверши авторизацию в своём аккаунте. Если твой Google Workspace запрещает анонимные приложения, этот вариант может быть недоступен.
6. Скопируй URL вида `https://script.google.com/macros/s/…/exec`. Адрес `/dev` предназначен для редакторов скрипта.

Это создаёт публичную точку обращения к твоему помощнику. Сервер вызывает Gemini от твоего имени с установленными ограничениями; посетители не получают API-ключ.

## 4. Подключи URL к портфолио

В `assistant-config.js` вставь только URL веб-приложения:

```js
window.PORTFOLIO_ASSISTANT_CONFIG = Object.freeze({
    endpoint: 'https://script.google.com/macros/s/ТВОЙ_АДРЕС/exec',
    timeoutMs: 60000
});
```

Этот адрес публичный; его можно прислать в чат для подключения. Обнови страницу локального портфолио с `Ctrl+F5`.

## 5. Проверь подключение

1. Открой `/exec` в отдельной вкладке. Ожидается JSON с `service: "almat-portfolio-assistant"`, `version: "2"`, `configured: true`. Этот GET только проверяет наличие конфигурации и не вызывает модель.
2. На сайте раскрой **Спроси о моих проектах** и спроси: «За что Алмат отвечал в дипломном проекте?».
3. Проверь ответ: PLC, SCADA и KUKA; общий результат должен быть описан как командный. У сгенерированного ответа будет подпись **ИИ-помощник**.
4. Спроси «А какие технологии используются в этом проекте?» для проверки контекста.
5. Проверь EN/RU, ссылки, новый диалог и отмену запроса. Попробуй окно без входа в Google для проверки публичного доступа.

Если появилось уведомление о недоступности и подпись **По материалам портфолио**, это локальный справочный ответ, а не ответ модели. Успешный GET сам по себе не проверяет ключ, модель или работу POST из браузера. Apps Script перенаправляет ответы Content Service на `script.googleusercontent.com`; клиент следует перенаправлениям и отправляет обычную форму без нестандартных заголовков. Ошибки CORS, входа или доступа нужно проверять на реальном развёрнутом приложении. `no-cors` использовать нельзя: он скрывает текст ответа.

## Обновление фактов и серверного кода

Факты о профиле находятся в `assistant-knowledge.js`, проекты — в `projects-data.js`, сервер — в `google-apps-script.gs`. После изменений пересобери единый файл:

```sh
node scripts/build-assistant-backend.cjs
```

Скопируй обновлённый `apps-script/Code.gs` в редактор, затем **Deploy → Manage deployments → Edit → New version → Deploy**. Обновление существующего развёртывания позволяет сохранить URL.

## Проверки кода

Для тестов нужен Node.js с `node:test`. Установка пакетов не требуется:

```sh
node tests/assistant-knowledge.test.cjs
node tests/chatbot-backend.test.cjs
node tests/chatbot-frontend.test.cjs
```

Тесты выполняют настоящие функции с моделями DOM и сервисов Apps Script. Они не отправляют запросы провайдеру и не заменяют визуальную проверку или тест CORS в браузере.

## Проверка подключённого развёртывания — 20 октября 2026 года

Адрес из `assistant-config.js` проверен прямыми HTTP-запросами без Google-входа: GET вернул `configured: true`, а два form POST-запроса вернули реальные ответы Gemini на английском и русском. Проверены личный вклад PLC/SCADA/KUKA, командное авторство и продолжение диалога с историей. Ответы и перенаправления содержали `Access-Control-Allow-Origin: *`. Это не заменяет проверку самого чата в браузере.

Русский тест занял около 42 секунд; в текущей конфигурации ожидание увеличено до 60 секунд. При более долгом ожидании сайт покажет уведомление и справочный ответ. Перезагрузи локальный сайт через `Ctrl+F5`, чтобы браузер получил новый адрес и настройку ожидания. Обновление файлов на GitHub Pages выполняется отдельно.
